# 검증된 Android 개발용 APK

binux 0.1.2와 Binux Desktop:X11 0.1.0의 ARM64 APK입니다. 운영 서명 대신 동일한 개발용 debug 서명을 사용합니다. 기존 binux 0.1.1 APK와 같은 인증서로 빌드하여 업데이트할 수 있습니다. 실제 휴대폰 X11 테스트는 대기입니다. Android 배포판 실행 엔진은 아직 포함하지 않습니다.

다운로드 파일은 `SHA256SUMS`로 확인하세요. 대응하는 전체 소스, GNU Bash와 X11 서드파티 소스 아카이브, GPL 및 각 구성요소의 라이선스가 같은 저장소에 있습니다. 빌드·설치·런타임 제한은 `docs/DESKTOP-X11.md`를 참고하세요.
