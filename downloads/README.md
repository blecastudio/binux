# binux 개발 배포 파일

최신 1.0.0 개발 프리뷰 파일과 설치 안내는 [1.0 디렉터리](1.0/README.md)에 있습니다.
Android ARM64용 binux·Desktop:X11 APK, Windows x64 ZIP, 서명된 공식 보조 패키지를 제공합니다.
APK는 기존 개발 서명으로 빌드하여 앱 데이터를 유지하는 업데이트 설치가 가능합니다.
선택형 Debian/Ubuntu VM 엔진을 포함하며 배포판 데이터는 별도로 설치합니다.
Android 실기기와 Windows GUI 실행 검증은 아직 완료하지 않았습니다.

이 디렉터리의 기존 0.1.2·Desktop:X11 0.1.0 파일과 SHA256SUMS는 이전 배포 기록입니다.
0.1.x APK에는 Debian/Ubuntu 실행 엔진이 포함되지 않습니다.

버전별 SHA256SUMS로 다운로드를 확인하세요. 전체 대응 소스와 Bash·QEMU·X11 소스/라이선스는
같은 저장소에 있습니다. 현재 사용법과 검증 범위는 [1.0 안내](../docs/RUNTIME-1.0.md)와
[상태표](../docs/STATUS.md)를 확인하세요.
