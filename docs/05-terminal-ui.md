# 5. Kotlin 터미널 UI

`MainActivity.kt`가 Compose 레이아웃 안에 실제 `TerminalView`를 연결합니다. ANSI/UTF-8, 커서 이동, 선택 복사, 붙여넣기, IME, 외부 키보드 입력은 vendored 터미널 라이브러리에서 처리합니다. Tab 및 방향키는 PTY에 바이트를 전송하므로 Bash의 실제 자동완성과 기록을 사용합니다.

새 세션 탭, 서로 다른 세션의 세로 분할, Ctrl/Alt 토글, Esc/Tab/방향키, Paste/Stop, 핀치 글꼴 크기, 저장된 font/theme/cursor 설정을 제공합니다. 검색은 세션 기록을 읽고 일치하는 줄을 표시합니다. 현재 Android theme 설정은 앱 UI 테마를 바꾸며 터미널 256색 팔레트 편집기는 아직 없습니다. 키보드 단축키 재매핑 UI도 후속 대상입니다.

세션 복원은 중단된 기록과 cwd에서 **새 셸**을 시작합니다. 이전 Bash 스택/실행 중이던 프로세스 복원은 하지 않습니다. 한국어 조합 입력, 분할 포커스, 소프트 키보드 리사이즈는 실기기 검증이 필요합니다.
